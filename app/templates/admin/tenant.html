How to connect a form

WordPress (Elementor Pro, WPForms, Gravity Forms): in the form's actions, add a Webhook pointing at the URL above. Field names are matched automatically (name, email, phone, address, message); anything unusual goes in the field map below.

Zapier / Shopify Flow / anything else: send a POST with JSON like this:

{
  "name": "Mike Reynolds",
  "phone": "705 555 0142",
  "email": "mike@example.com",
  "job_address": "12 Birch Lane, Bracebridge",
  "job_type": "Roof replacement",
  "message": "Please call about a quote",
  "gclid": "", "fbclid": "", "utm_source": "", "utm_campaign": "",
  "landing_page": "https://..."
}

Test it from a terminal:

curl -X POST '{{ intake_url }}' -H 'Content-Type: application/json' \
  -d '{"name":"Test Lead","phone":"705 555 0100","job_type":"Test","message":"Delete me"}'
Attribution snippet (which ad brought the lead)

Add this to every page of the client's site, in Google Tag Manager as a Custom HTML tag firing on All Pages (or in the theme's footer). It remembers gclid / fbclid / UTMs for 90 days and fills them into every form, so a lead that converts three visits later is still credited to the ad.

<script src="{{ snippet_url }}" async></script>

WordPress forms: Elementor Pro, WPForms and Gravity post only the fields they know about, so add hidden fields named gclid, fbclid, utm_source, utm_medium, utm_campaign, utm_term, landing_page and referrer to the form (hidden-field type, no default value). The snippet fills them. Forms that post every input (custom HTML, Shopify theme forms) need nothing extra.

Wix / Squarespace: their form builders mostly can't carry hidden fields; those leads arrive as "Website" without the ad detail. Enhanced Conversions (phase 4) still matches them to the ad by email and phone.

Also in GTM, once per site: the Google tag with user-provided data collection on, and the Meta pixel. That is what lets the CRM's Qualified / Won uploads match leads that have no click id.

Texting number (Twilio)

On the client's Twilio number, under Voice & Fax and Messaging, point both webhooks at the CRM (HTTP POST):

A message comes in
{{ settings.base_url }}/v1/twilio/sms
A call comes in
{{ settings.base_url }}/v1/twilio/voice

Texts from leads land on the lead and are relayed to the assignee's phone from this number; whatever the assignee texts back goes to the lead. Calls to the number ring the forwarding number below (or the owner's mobile) showing the caller's own number, and are logged on the lead.

CallRail

In CallRail: Settings → Integrations → Webhooks for this client's company, add a Post-call webhook:

Webhook URL
{{ callrail_url }}

Answered calls of {{ call_min_seconds }} s or more become leads (or log on the existing lead for that number, as contact). Missed calls, voicemails and shorter calls become leads flagged Missed call with an immediate call-back alert. Calls tagged spam, vendor, solicitor, existing customer, wrong number or not a lead are dropped. The source, campaign, keyword, landing page, gclid and recording link come across with the call. Change the minimum under Settings below.
